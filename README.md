# JZINJECTLINK ⚡

Web bypass safelink & ekstraktor link download langsung (MediaFire, Google Drive, Mega.nz, dll) tanpa iklan, dilengkapi sistem keamanan verifikasi anti-robot dan asisten AI terintegrasi (Google Gemini & OpenAI GPT).

---

## 🌟 Fitur Utama

- 🚀 **Bypass & Ekstraksi Cepat**: Ekstrak link download asli dari URL safelink/shortener (SafelinkU, SafeFile, Bit.ly, dll) dalam hitungan detik.
- 🛡️ **Verifikasi Anti-Robot (JZ Shield)**: Proteksi anti-bot wajib centang sebelum convert link untuk mencegah spam otomatis.
- 🤖 **JZ AI Assistant**: Widget Chat AI mengambang dengan integrasi **Google Gemini** dan **OpenAI (GPT)** serta fallback knowledge base bawaan.
- 📱 **100% Responsif & Mobile Friendly**: Dilengkapi menu drawer hamburger, tata letak sentuh ramah jari, dan tampilan putih-biru modern.
- 💬 **Komunitas Discord**: Tautan terintegrasi langsung ke server Discord [JZ Community](https://discord.gg/rWgevvub).

---

## 📂 Struktur Project

## 🚀 Cara Menjalankan

Cukup buka file `index.html` langsung di browser pilihan Anda (Google Chrome, Firefox, Edge, Safari) tanpa perlu instalasi server tambahan.
